Publicador Forja – Publicador de Vídeos Curtos

Ferramenta interna da SOUL ESTUDIO LTDA para publicar os vídeos curtos originais de Guilherme Cristofore nas contas oficiais da empresa: YouTube, Instagram (@guilhermecristoforeofc e @cortes.guilhermecristofore) e TikTok.

Esta ferramenta usa APIs oficiais: Serviços de API do YouTube (YouTube API Services), Instagram API da Meta e TikTok Content Posting API.
Ao utilizá-la, você concorda com os Termos de Serviço do YouTube, a Política de Privacidade do Google, os Termos de Serviço do TikTok e os Termos de Uso do Instagram.

O que a ferramenta faz

  • Lê o calendário editorial da equipe (Google Sheets): título, descrição, tags e data de publicação.
  • Na data e hora definidas, publica o vídeo nas contas da própria empresa (YouTube Data API v3, Instagram API e TikTok Content Posting API).
  • Atualiza o status da publicação na planilha.

Quem pode usar

Somente o titular do canal e sua equipe interna. A ferramenta não é vendida nem oferecida a terceiros, não acessa contas de terceiros e não coleta dados de espectadores ou seguidores.
